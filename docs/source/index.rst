MILES-ClimateSleuth documentation
==================================

MILES-ClimateSleuth provides reusable tools for contrastive learning, latent-space
evaluation and explainable AI for
climate-model development workflows.

The package is organized in the same spirit as other MILES packages: stable,
reusable building blocks live in ``climatesleuth``; experiment-specific training,
plotting, and HPC job scripts live under ``scripts`` or notebooks.
